┃                                           🧠 LangGraph 的特点                                            ┃
┃                                                                                                          ┃
┃  • 图结构编排：将工作流建模为图，节点是计算步骤，边是状态转移                                            ┃
┃  • 强流程控制：原生支持条件分支（如 if/else）和循环（如重试、迭代）                                      ┃
┃  • 状态管理：有显式的状态（State），可在节点间传递信息                                                   ┃
┃  • 灵活性极高：适合构建 RAG、复杂管线、可动态决策的 Agent                                                ┃
┃  • 依赖 LangChain：可与 LangChain 的模型、工具无缝集成                                                   ┃
┃                                                                                                          ┃
┃                                                                                                          ┃
┃                                             👥 CrewAI 的特点                                             ┃
┃                                                                                                          ┃
┃  • 角色驱动：每个 Agent 有明确的角色、目标、背景故事                                                     ┃
┃  • 团队协作：通过 @task 分工，由 Crew 统一调度协作                                                       ┃
┃  • 内置工具与流程：开箱即用的 process（sequential / hierarchical）                                       ┃
┃  • 上手快：代码简洁，适合快速搭建多 Agent 应用                                                           ┃
┃  • 偏向任务分配：类似"项目经理"分配 Agent 干活                                                           ┃

┃  • 选 CrewAI 当：需要多角色 Agent 协作，任务可分解给不同"专家"，追求快速搭建。                           ┃
